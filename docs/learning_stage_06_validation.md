# 阶段06：滚动验证

本页命令均在项目根目录执行，`python`指本项目独立环境；未激活时用 `.\.venv\Scripts\python.exe` 替代。代码中的教学小例子不用于业务结论。

## 要理解的问题

随机划分会把未来业务模式带入过去。扩展窗口模拟真实时间顺序：截至8月训练、9月验证；截至9月训练、10月验证；截至10月训练、11月验证。三个验证月等权平均WAPE，决定方案。12月不参与模型选择或早停。

## 本项目的做法

比较三种朴素基准和31/63叶的LightGBM Poisson。两个模型都以L1验证误差早停，学习率0.05、上限2000轮、早停100轮、种子42。Poisson目标适合非负计数，但不保证一定更准。锁定方案后，用1—11月重训，轮数取验证阶段最佳轮数中位数，再评估12月。基准与模型使用完全相同的有效区域小时。

## 自检练习

练习：在 model_selection.json 中指出选择依据、训练截止、验证开始和固定重训轮数。尝试只看12月挑模型，说明为什么这样破坏独立测试。

## 动手步骤与检查点

运行 `python -m src.run_pipeline --stage train --seed 42`。检查 model_selection.json 的三个 split：每个 train_end 都必须早于 validation_start。读取 validation_metrics.csv，先按月计算WAPE，再对三个验证月等权平均；不要把三个月的全部行合并后当作等权结果。

训练最多2000轮、早停100轮；最终轮数只从验证阶段最佳轮数取中位数。若最佳轮数达到上限，它只说明本次限制内选择了该轮数，不代表已经证明训练充分收敛。

练习答案：根据12月误差重新选择配置会消耗独立测试集，最终结果成为选择后结果。若希望继续调参，应另设未来测试月份；本项目保留既定协议，未扩大搜索空间来追求更漂亮数字。

输入记录和模型保存文件应一起保留。只保存一个最终WAPE，无法追溯训练截止、选择依据或是否重看过测试集。
