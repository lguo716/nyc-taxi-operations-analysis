# 阶段07：预测评估

本页命令均在项目根目录执行，`python`指本项目独立环境；未激活时用 `.\.venv\Scripts\python.exe` 替代。代码中的教学小例子不用于业务结论。

## 要理解的问题

WAPE=绝对误差合计/实际记录合计，衡量相对于总规模的误差；MAE表示每区域小时平均错多少次；RMSE更重视大误差。WAPE会被高需求区域主导，因此要同时看各区域、行政区和小时误差。低流量区域零值较多，逐条MAPE不稳定，本项目不使用它。

## 本项目的做法

零需求分母返回空值，不能伪装为0%误差。测试预测包含所有候选方案，报告既展示验证选定方案，也保留其他方案的独立结果。逐日趋势是每小时预测汇总，不是次日一次性预测。测试期间允许使用已经结束的测试小时作为下一小时的滞后，这是滚动一步评估；模型权重不因12月结果重训。

练习：手算实际[0,10]、预测[2,8]的WAPE、MAE和RMSE。选择一个误差较大的区域，判断主要是规模误差、偏差还是偶发峰值。

## 动手步骤与检查点

运行 `python -m src.run_pipeline --stage evaluate --seed 42`；核对 test_metrics、test_zone_metrics、test_errors_by_group 和逐小时 forecast_hourly。五个候选方案必须使用相同样本，才可公平比较。

练习答案：实际[0,10]、预测[2,8]时，绝对误差合计4，WAPE=4/10=40%，MAE=4/2=2，RMSE=√((4+4)/2)=2。若实际全为0，则WAPE无定义，MAE和RMSE仍可计算。

误差切片至少看区域、行政区和目标小时。对某区而言，相对误差大可能只是基数小；对高需求区而言，相对误差不大仍可能贡献大量绝对误差。不要用区域WAPE的简单平均替代全区域WAPE。

逐日合计图是核对规模的辅助图，可能掩盖同一天不同区域误差互相抵消。最终验收仍以区域小时的绝对误差计算，而不是对总量曲线重新评估。
