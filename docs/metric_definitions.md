# 指标、粒度与有效分母

## 数据范围

2025年Yellow Taxi每月全文件。来源月内有效上车时间、非明确payment_type=6作废、上车区域1—263构成需求口径。区域1为Newark Airport；264未知与265无法映射区域单独记入排除表。负金额、零里程与时间异常不全局删除需求记录。相同原字段记录保留，未声称存在唯一订单号。

## 运营指标

| 指标 | 分子 / 分母及过滤 | 单位 |
|---|---|---|
| 上车记录 | demand_valid的行数 | 次；不等于所有潜在需求 |
| 平均计价车费 | 有效fare_amount合计 / fare_n | USD/次 |
| 乘客总支付 | 有效total_amount合计 | USD；含费用和已记录小费，不是平台收入 |
| 平均距离/时长/速度 | 对应效率有效值合计 / efficiency_n | km、分钟、km/h |
| 银行卡小费率 | tip_valid记录tip_amount合计 / 同一记录fare_amount合计 | 比率；包含零小费，不含现金小费 |
| 标记率 | demand_valid内任一质量标记行数 / demand_valid行数 | 比率；不等于违规率 |
| 日均记录 | 当前日期/区域选择下记录合计 / 当前日期集合天数 | 次/天；缺失日期不可当零 |

fare_valid：payment_type为0/1/2，fare_amount与total_amount正且有限，没有已列金额字段负值、费用极端或缺失。筛查上限为fare_amount1000、total_amount2000、tip_amount1000美元。efficiency_valid：0<duration_min<=180、0<trip_distance<=100英里、0<=speed_kmh<=130，且上/下车日期都不在2025-03-09、2025-11-02。两个过渡日保守排除效率分母，需求保留。tip_valid再限定payment_type=1且tip_amount有限。CSV保留所有总量和有效次数，DAX重新加权。

## 预测指标

共同有效区域小时样本；基准和机器学习完全相同。WAPE=Σ|预测-实际|/Σ实际；MAE=Σ绝对误差/N；RMSE=√(Σ平方误差/N)。实际和为0时WAPE为空。9/10/11月平均WAPE选择模型，12月只验收。每次预测[t,t+1)，可使用已结束的测试小时做下一小时滞后，不能用目标小时实际量。四周基准需672小时预热。

## 模拟指标

给定名额B，权重按比例分配并用最大余数法整数化，每小时所有区域名额和=B。三策略为均匀、四周历史均值、验证选定预测。覆盖=min(实际,名额)；未覆盖=实际-覆盖；闲置=名额-覆盖；覆盖率=覆盖合计/实际合计；名额利用率=覆盖合计/名额合计。区域筛选只截取固定全区域分配，三策略实际量重复时不能跨策略相加。服务名额不是车辆数，没有真实成本、收入或空驶率。
